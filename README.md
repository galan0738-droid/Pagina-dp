#  Tributo a FromSoftware

Página web dedicada a recopilar los mayores éxitos, música y videos de los títulos más emblemáticos desarrollados por **FromSoftware**.

##  Contenido de la página
* Recopilación de juegos destacados (Dark Souls, Bloodborne, Sekiro, Elden Ring, etc.).
* Galería multimedia con tráilers, escenas y música icónica.
* Diseño estructurado en HTML puro.

## Tecnologías utilizadas
* HTML5
* Multimedia local (Audio y Video)
